# 옵시디언 플러그인 선택

볼트에 LLM을 붙이는 방법은 크게 세 갈래입니다. 셋 다 같은 마크다운 폴더 위에서 동작하므로 병행할 수 있습니다.

## A. 옵시디언 안에서 (플러그인)

- **Smart Connections** — 노트를 자동 임베딩해 "지금 보는 노트와 비슷한 노트"를 사이드바에 띄우고, 볼트 대상 채팅을 제공합니다. 설정이 가장 쉽습니다.
- **Copilot for Obsidian** — 볼트 전체 색인 + 채팅. 사용할 LLM 제공자와 임베딩 제공자를 직접 지정합니다.
- **Text Generator / Local GPT** — 노트 작성 중 생성 보조에 가깝고, 검색보다 작성 지원 성격입니다.

장점: 설치가 곧 완성. 단점: 청킹/검색 로직이 블랙박스라 튜닝과 평가가 어렵습니다.

## B. 볼트 밖에서 (직접 만든 파이프라인)

폴더를 읽어 색인하고 CLI/웹/슬랙 봇으로 질의합니다. 이 저장소의 `rag/` 가 이 방식입니다.

장점: 청킹, 검색, 프롬프트, 평가를 전부 통제할 수 있고 팀 공용 서비스로 확장됩니다.
단점: 코드를 관리해야 합니다.

## C. 에이전트에게 폴더를 그냥 준다

Claude Code 같은 에이전트를 볼트 디렉터리에서 실행하면 `grep`/파일 읽기로 스스로 탐색합니다.
색인이 아예 필요 없고, 노트 수정까지 시킬 수 있습니다. 볼트가 아주 크면 탐색 비용이 커집니다.

## 권장 조합

1. 개인용은 A로 시작한다.
2. 팀 위키가 되는 순간 B를 만든다. 평가셋 없이 튜닝하는 것은 불가능하기 때문입니다. [[RAG 품질 평가]] 참고.
3. 노트를 고치거나 정리하는 작업은 C에게 맡긴다.
